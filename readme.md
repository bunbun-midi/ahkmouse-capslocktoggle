autohotkey v1 script for using the mouse with the right hand in ijkl position using capslock as a modal toggle to enable these hotkeys

Controls with Caps Lock on::
Key or combination //\//\//	Action
I / J / K / L	--Move mouse up / left / down / right
Alt + I/J/K/L	-- Move mouse at 2× speed
Shift + I/J/K/L --	Send up / left / down / right arrow
Space, H, or ; --	Left mouse button—press, hold, release
U or O ::	Right mouse button—press, hold, release
8:	Mousewheel down
9:	Wheel up
F7 : middle mouse button
